# OpenRA Red Alert combat audio attribution

The WAV files in this directory are original Red Alert effects extracted from
OpenRA's checksum-verified `ra-base.zip` package (SHA-1
`aa022b208a3b45b4a45c00fdae22ccf3c6de3e5c`) using
`scripts/import-openra-audio.mjs`.

These game assets are separate from OpenRA's GPL engine source and from this
project's source code. Original Red Alert audio is © Electronic Arts and is
provided under the C&C Franchise Modding Guidelines. OpenRA's legal notice is
available at <https://www.openra.net/legal/>.
